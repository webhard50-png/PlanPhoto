# 평면도 사진 (Android)

PDF 건축 평면도 위에 핀을 놓고, 핀을 누르면 카메라가 열려 그 위치의 사진을 남기는 앱입니다.

## 기능
- **새 파일 만들기**: 첫 화면 아래 `새 파일 만들기`를 눌러 PDF 평면도를 고르거나, 카카오톡·드라이브 등에서 PDF를 "다음으로 열기 → 평면도 사진".
- **핀 배치**: `+ 핀 추가` → 도면을 누르면 원형 카메라 핀이 생깁니다(원의 가운데가 위치, 아래 꼬리표가 핀 번호, 오른쪽 위 숫자가 촬영 횟수, 사진이 없으면 연한 색). 두 손가락으로 확대, 한 손가락으로 이동, 두 번 탭하면 확대/원래대로.
- **바로 촬영**: 핀을 누르면 앱 안 카메라가 바로 열립니다. 셔터(또는 볼륨 버튼)를 누르면 확인 없이 즉시 저장되고,
  화면이 그대로라 같은 위치를 연속으로 찍을 수 있습니다. `완료`로 도면에 돌아갑니다.
  `+ 핀 추가` 중에는 핀을 놓자마자 카메라가 열립니다. 휴대폰을 가로로 돌려 찍어도 사진 방향이 맞게 저장됩니다.
  (카메라 권한을 허용하지 않으면 휴대폰 기본 카메라 앱으로 찍을 수 있습니다.)
- **핀 삭제**: 도면 화면 아래 `핀 삭제`를 누른 뒤 지울 핀을 누르면 확인 후 삭제됩니다(핀을 길게 눌러 나오는 메뉴에서도 가능).
- **저장 방식**: 한 번 찍으면 두 장이 저장됩니다.
  - `..._원본.jpg` : 카메라 원본 그대로
  - `..._좌표.jpg` : 사진 아래에 핀 주변 도면 확대, **X·Y 좌표**, **촬영 날짜·시간**, 도면 이름·쪽을 표시
- **날짜별 저장**: 같은 핀에서 여러 번 찍으면 날짜 폴더로 나뉩니다. 핀을 길게 누르면 → `사진 기록 보기`에서 날짜별로 볼 수 있습니다.
- **파일 이름 = 좌표_날짜_시간**: `X0004520_Y0012300_20261010_140732_좌표.jpg`
  좌표는 mm 정수 7자리로 맞춰, 이름순 정렬 시 좌표 → 날짜 → 시간 순으로 나열됩니다.
- **좌표 기준**: 도면 용지 기준 mm, 원점은 도면 **좌하단**, X는 오른쪽, Y는 위쪽.
- **휴대폰 저장 폴더 = 내장 메모리(SDCARD)/PDFPIC**: 좌표 사진과 원본 사진이 **모두 이 한 폴더에** 저장됩니다(`/sdcard/PDFPIC/`).
  파일 이름이 `X좌표_Y좌표_날짜_시간_좌표/원본.jpg` 이므로 '내 파일' 앱에서 이름순으로 정렬하면 좌표 → 날짜 → 시간 순으로 나열됩니다.
  내보내기 ZIP도 이 폴더에 저장됩니다. 처음 실행할 때 **'모든 파일 접근' 권한**을 요청합니다(Android 11 이상 필수).
  허용하지 않으면 사진은 `사진/PDFPIC`, ZIP은 `다운로드/PDFPIC`에 대신 저장되며, 첫 화면 메뉴 ⋮ → `저장 폴더 (PDFPIC)`에서 다시 설정할 수 있습니다.
  (앱 안의 사진 기록 화면은 따로 핀·날짜별로 정리해 보여 줍니다.)
- **촬영 방향**: 핀을 길게 누르고 `방향 표시`를 고른 뒤, 핀 주변을 한 손가락으로 끌면 그쪽으로 시야 부채꼴(60°)이 돌아갑니다(5° 단위, 두 손가락 확대 가능). `방향 완료`로 끝냅니다.
  방향은 도면 위쪽 0°, 시계 방향이며 좌표 사진의 도면 확대 부분과 글자(예: `방향 45° 오른쪽 위↗`)에 함께 표시됩니다.
- **핀 메뉴(길게 누르기)**: 사진 촬영 · 사진 기록 보기 · 방향 표시/조절 · 이름 변경 · 위치 이동 · 삭제 · 방향 지우기
- **한글 이름**: 도면·핀 이름을 바꿀 때 입력창이 한글 키보드로 바로 열립니다. 맥·아이폰이나 메신저에서 받은 PDF 이름의
  깨진 한글(자모 분리, %ED… 형태)은 불러올 때 자동으로 바로잡습니다.
- **도면 목록에서 파일 이름을 누르면**: 도면 열기 · 내보내기(PDF + 사진 ZIP) · 평면도 PDF 교체 · 이름 변경 · 사진 전체 공유 · 삭제
- **평면도 PDF 교체**: 수정된 도면으로 바꿔도 핀·방향·사진은 그대로입니다. 새 PDF는 **기존 도면 크기에 맞춰** 같은 비율로 확대/축소되어
  가운데에 놓이므로(A1 → A3처럼 용지만 달라져도 위치가 맞음) 좌표도 바뀌지 않습니다. 용지 비율이 다르면 남는 부분은 흰 여백입니다.
  이전 PDF는 앱 안에 `_rev1`, `_rev2`…로 보관됩니다. 도면 화면 메뉴 ⋮에서도 교체할 수 있습니다.
- **내보내기**: 도면 목록에서 파일 이름을 누르고 `내보내기`를 고르면(도면 화면 메뉴 ⋮에도 있음) ZIP 하나로 묶어
  **PDFPIC 폴더에 저장**하거나 **공유**(카톡·메일·드라이브)할 수 있습니다. ZIP 안에는
  원본 PDF, 핀 번호·방향을 그려 넣은 `_핀표시.pdf`, 핀/날짜별 폴더의 좌표 사진·원본 사진,
  엑셀에서 열리는 `사진목록.csv`(핀, 쪽, X·Y mm, 방향, 촬영일시, 파일 이름)가 들어 있습니다.
  저장 위치: `내장 메모리/PDFPIC/도면이름_20261010_1452.zip`
- **공유**: 도면/핀 단위로 좌표 사진만, 원본만, 또는 모두 공유(카톡·메일 등).

## APK 만들기 — 방법 1: GitHub (Android Studio 설치 없이)
1. GitHub에서 새 저장소를 만들고 이 `PlanPhoto` 폴더 내용을 그대로 올립니다(`.github` 폴더 포함).
2. 올리면 자동으로 빌드가 시작됩니다(약 5~10분). 저장소의 **Actions** 탭 → 최근 실행 → 아래 **Artifacts**의 `PlanPhoto-apk`를 내려받으면 `app-debug.apk`가 들어 있습니다.
   저장소의 `apk` 브랜치에도 `PlanPhoto.apk`로 올라갑니다.
3. APK를 휴대폰에 옮겨 누르면 설치됩니다(처음에 '출처를 알 수 없는 앱 설치 허용'을 켜야 할 수 있습니다).

## APK 만들기 — 방법 2: Android Studio
1. [Android Studio](https://developer.android.com/studio) 설치 (Koala 2024.1 이상).
2. `File → Open` 으로 이 `PlanPhoto` 폴더를 엽니다. Gradle 동기화가 끝날 때까지 기다립니다.
3. 휴대폰을 USB로 연결하고 개발자 옵션의 USB 디버깅을 켠 뒤 ▶ Run → 바로 설치됩니다.
4. 설치 파일만 필요하면 `Build → Build App Bundle(s) / APK(s) → Build APK(s)`
   → `app/build/outputs/apk/debug/app-debug.apk` 를 휴대폰에 복사해 설치.

요구 사항: Android 10 이상. 처음 실행할 때 '모든 파일 접근'(PDFPIC 폴더 저장), 처음 촬영할 때 카메라 권한을 묻습니다.
'모든 파일 접근' 권한 때문에 Play 스토어 등록에는 별도 심사가 필요하며, APK로 직접 설치하는 경우에는 문제없습니다.

## 파일 구성
- `PlanActivity.kt` – 도면 화면, 핀 추가/이동, 쪽 넘김
- `PlanView.kt` – 도면 확대·이동, 핀 그리기, 터치 판정
- `CameraActivity.kt` – 앱 안 카메라 (바로 저장, 연속 촬영, 볼륨 버튼 셔터)
- `CaptureActivity.kt` – 카메라 열기, 기본 카메라 앱 대체 경로
- `PhotoSaver.kt` – 촬영 후 좌표 사진 만들기와 기록
- `PhotoProcessor.kt` – 좌표 계산, 좌표 사진 합성, 핀 모양
- `PhotosActivity.kt` – 핀별 사진 기록(날짜별)
- `Exporter.kt` – PDF + 사진 ZIP 내보내기, 핀 표시 PDF, 사진 목록 CSV
- `PdfPages.kt` – 기준 크기에 맞춰 PDF 그리기 (교체해도 핀 위치 유지)
- `PdfReplace.kt` – 평면도 PDF 교체 화면 흐름
- `Names.kt` – 한글 이름 입력창, 깨진 한글 파일 이름 정리
- `PdfPicStorage.kt` – 내장 메모리/PDFPIC 폴더 저장과 권한 요청
- `Repo.kt` – 데이터 저장(JSON), 파일 이름 규칙, 갤러리 복사, 공유
